# Design documents

Each document explains why a set of anchors or decisions changed. The [contribution guide](contributing.md) describes what to submit and how we review it. Start a new document with the [template](design-documents/template.md).

- [Bootstrapping the design anchors](design-documents/bootstrap.md) records where the original anchors came from and how to interpret them.
- [When a change needs a design document](design-documents/process.md) explains the rule, including what to do when a bug fix reveals a design change.
